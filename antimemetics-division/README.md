# Antimemetics Division

**A multimedia knowledge system exploring SCP Foundation concepts, religious/mythological frameworks, and information-resistant entities.**

This is a collaborative space for:
- **Music & Audio**: Original compositions, samples, and remixes (Suno, YouTube, Spotify, community contributions)
- **Narrative & Theory**: Canonical knowledge base of antimemetic concepts, gnostic theology, and mythological frameworks
- **Interactive Experiences**: Web apps, explorers, and immersive environments
- **Research & Analysis**: Cross-disciplinary investigation into how ideas resist being remembered/transmitted

### 🎵 Music Access
Music is sourced from:
- **Suno AI**: Generated tracks with IDs linked to original projects
- **YouTube/Spotify**: Embedded with metadata & attribution
- **Community**: Submit via Pull Request
- **Archives**: Linked from `The-Crystal-Vision-System/archive/TerAustralis-Incognita/mythos/music/`

Each track includes:
- Artist/source attribution
- Creation date
- Related narrative/canon references
- License (CC0, CC-BY, commercial rights where applicable)

### 📖 Knowledge System
The `narrative/canon.md` is **the single source of truth** for this project, built on the Incognita Rule:
- **Built**: Verified, with evidence on disk
- **Vision**: Proposed/theoretical
- **Unknown**: Unresolved questions

Read `narrative/canon.md` first. Sessions append new discoveries with evidence levels and sources.

## Contributing

### For Collaborators
1. **Read** `narrative/canon.md` and `GOVERNANCE.md` first
2. **Verify**: All claims need evidence references
3. **Source**: Link music to original creators (Suno, artists, URLs)
4. **License**: Respect content licensing (see `LICENSE.md`)
5. **Append**: Update canon with dated session logs, never rewrite canon directly

### For Musicians
1. Submit tracks via PR or discussion
2. Include metadata: title, date, description, license, source (Suno ID / YouTube / original)
3. Optionally: narrative themes, emotional tone, associations

### For Developers
1. Choose an interactive stack (see `docs/`)
2. Build from the canonical knowledge base
3. Link music + narrative + research together
4. Document your approach in project README

### For Researchers
Contribute to `narrative/research/` with:
- Cross-disciplinary analysis (theology, memetics, information theory)
- Evidence-gathering (books, papers, verified sources)
- Hypothesis exploration (tagged as "proposed" until verified)
